# Role: Expert UI/UX Designer & Full-Stack Web Developer

# Project: Official Website for Micro-SaaS Startup "Bigeen Solutions"

## 1. Project Context

You are tasked with designing and architecting a production-ready, high-converting website for a micro-SaaS startup named **Bigeen Solutions**. The website must balance aesthetic appeal with functional clarity, ensuring visitors immediately understand the value proposition while seeing a clear history and future trajectory of the company.

**Brand Core:**

- **Name:** Bigeen Solutions
- **Slogan:** "The future of integrated Business Tools"
- **Vibe:** Professional, Futuristic, Minimalist, Trustworthy, and High-Tech.

## 2. Visual Aesthetic & Industry Trends

The design must strictly adhere to current 2024/2025 SaaS web design trends.

- **Style:** "Bento Grids" layout for features, subtle glassmorphism on cards, and large, clean typography (Sans Serif).
- **Color Palette:**
  - **Primary:** Deep Navy Blue / Midnight Blue (Trust & Tech).
  - **Accent:** Electric/Neon Purple or Teal (Future & Integration).
  - **Background:** Clean White/Off-White for light mode, with a "System Dark Mode" option.
- **Motion:** Scroll-triggered animations (fade-ins), micro-interactions on buttons, and a smooth parallax effect on the Hero section.
- **Typography:** Inter or DM Sans for body; Space Grotesk for headers.

## 3. Site Architecture & Content Requirements

Please outline the content, layout, and component structure for the following key pages:

### A. Homepage (The Conversion Engine)

- **Hero Section:** High impact. Headline centered. Subtext explaining the slogan ("The future of integrated Business Tools").
  - _CTA:_ "Get Early Access" or "Start Free Trial".
  - _Visual:_ An abstract 3D illustration or a high-fidelity dashboard mockup floating in isometric view.
- **Social Proof:** "Trusted by" ticker with monochrome logos.
- **Value Proposition:** 3-column grid explaining the "Integrated" aspect (e.g., Automation, Analytics, Scalability).

### B. The "Projects & Roadmap" Page (Critical Requirement)

This section is unique to Bigeen. It must transparently display the startup's journey.

- **Structure:** A vertical timeline or a Kanban-style board.
- **Categories:**
  1.  **Legacy/Old Projects:** Case studies of previous successful deployments.
  2.  **Current Projects:** What is live right now (The core Micro-SaaS product).
  3.  **Upcoming/In-Development:** A "Public Roadmap" showing features or tools currently in the lab (e.g., "Coming Q4 2025").
- _Feature:_ Allow users to "Vote" on upcoming features (simulated UI element).

### C. Updates & Blog

- A masonry-style grid layout for company news, changelogs, and thought leadership.

## 4. Technical Specifications (Production Ready)

- **Tech Stack Recommendation:** React + Tailwind CSS + Framer Motion (for animations).
- **SEO:** Structure semantic HTML (H1, H2, H3 tags).
- **Performance:** Design for Core Web Vitals (LCP, CLS, FID).
- **Responsive:** Mobile-first approach.

## 5. Required Output

Based on the instructions above, please provide:

1.  **Detailed Wireframe:** Text-based layout of the Homepage and the Projects Page.
2.  **Copywriting:** Draft the H1, H2, and Intro paragraph for the Hero section using the slogan.
3.  **Component Specs:** A description of the "Project Timeline" component including how it distinguishes between Old, New, and Upcoming projects visually.
4.  **Color Codes:** Specific Hex codes for the suggested palette.
